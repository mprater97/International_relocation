# 🏠 Domain Property Grabber — Chrome Extension

One-click save Domain.com.au rental listings to your relocation tracker.

## Install (2 minutes)

1. Open Chrome → go to `chrome://extensions/`
2. Turn ON **Developer mode** (top right toggle)
3. Click **"Load unpacked"**
4. Select this `chrome-extension` folder
5. Done! You'll see a green 🏠 button on Domain listing pages.

## How to Use

1. Browse Domain.com.au rental listings as normal
2. When you find one you like, click the green **"🏠 Save to Tracker"** button (bottom right)
3. It extracts: address, suburb, rent, beds, baths, cars, main photo, features (garden/pool/AC)
4. Click **"→ Open in Tracker"** to send it directly to your relocation tracker
5. The property appears in your Move Plan → Houses tab automatically

## What it Grabs

- ✅ Address
- ✅ Suburb  
- ✅ Rent ($/wk)
- ✅ Bedrooms, bathrooms, car spaces
- ✅ Main listing photo
- ✅ Features (garden, pool, air con, dishwasher)
- ✅ Listing URL

## Troubleshooting

- **Button doesn't appear?** — Only shows on individual listing pages, not search results
- **Missing data?** — Some fields may not extract if Domain changes their page structure. You can edit in the tracker.
- **"Open in Tracker" doesn't work?** — Copy the data manually (it's on your clipboard) and paste into the tracker URL field

## Privacy

- This extension ONLY runs on domain.com.au
- It does NOT send data anywhere except your own tracker (GitHub Pages)
- No analytics, no tracking, no third-party servers
